# Computer

**Unstable - Unstable - Unstable**
This plugin is under active development!

Computer is a [Pumpkin](https://pumpkinmc.org/) plugin that aims to empower everyone to create next-generation immersive and interactive player experiences and stories.

Whether you want to build interactive quests, dynamic events, complex gameplay mechanics, or entirely new ways for players to interact with your world, Computer provides the tools and infrastructure to bring your ideas to life.

## Features

- **Extensible architecture** — Build and extend Computer through independent extensions.
- **Visual editor** — Design, organize, and manage your creations through a dedicated web-based panel.
- **Entry-based system** — Create reusable, configurable building blocks that define your own interactions and behaviors.
- **Interactive experiences** — Build dynamic player interactions, branching scenarios, and immersive stories.
- **Multi-language support** — Develop extensions just like you would develop a Pumpkin plugin, using Computer's WIT system.

## Architecture

Computer is built around three main components:

- **Engine** — The core runtime responsible for managing entries, coordinating execution, and handling player interactions.
- **Panel** — A web-based visual editor used to create, configure, and manage pages and entries.
- **Extensions** — Independent modules that provide new entry types and extend the engine's capabilities.
